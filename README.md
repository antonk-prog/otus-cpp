# fashion_mnist

Инференс ML-модели классификации изображений Fashion MNIST на C++.

Реализован **многослойный перцептрон (MLP)** — точность **0.885** на проверочной выборке
(вторая по качеству после CNN на Tensorflow 0.91, но не требует тяжёлых зависимостей).

Модель: 784 → 128 (сигмоида) → 10 (softmax), без свободных членов (Keras `use_bias=False`).
Вход нормируется делением на 255. Поскольку softmax монотонен, для выбора класса
достаточно argmax по логитам. Нулевые пиксели (фон, ~80% изображения) в суммировании
пропускаются.

## Формат данных

- `test.csv` — текстовый CSV без заголовка (разделители — запятая или пробел):
  в первом столбце номер класса, далее 784 целых числа (0..255) — байты
  изображения 28×28, развёрнутые по строкам.
- Модель — каталог с двумя файлами весов (сохранены из Keras `get_weights()` «как есть»):
  - `w1.txt` — матрица 784×128 (входы × нейроны скрытого слоя);
  - `w2.txt` — матрица 128×10 (нейроны × классы).

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/fashion_mnist test.csv model_dir
0.885
```

Аргументы: файл с тестовыми данными и каталог модели (`w1.txt`, `w2.txt`).
Программа выводит accuracy — долю правильных ответов. 18 000 изображений
обрабатываются примерно за 0.4 с.
