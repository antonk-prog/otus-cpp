# bayan

Утилита обнаружения файлов-дубликатов по содержимому на основе библиотеки Boost.

## Сборка и установка

```bash
cmake -S . -B build
cmake --build build
cd build && cpack -G DEB   # пакет bayan-*.deb
```

## Параметры командной строки

```bash
bayan -d <dir> [-d <dir>...] [параметры]
```

| Параметр | Описание |
|---|---|
| `-d, --path <dir>` | директория для сканирования, можно указывать несколько раз |
| `-e, --exclude <dir>` | директория, исключаемая из сканирования, можно указывать несколько раз |
| `-l, --level <n>` | уровень сканирования, один на все директории; `0` — только указанная директория без вложенных; по умолчанию — без ограничения |
| `-m, --min-size <n>` | минимальный размер файла в байтах (файлы строго больше указанного значения); по умолчанию `1` — проверяются все файлы больше 1 байта |
| `-n, --mask <mask>` | маска имени файла (`*`, `?`), не зависит от регистра; можно указывать несколько раз; по умолчанию — все файлы |
| `-s, --block-size <n>` | размер блока `S` в байтах, которым производится чтение файлов; по умолчанию `4096` |
| `-a, --hash <algo>` | алгоритм хэширования блоков `H`: `crc32` или `md5`; по умолчанию `crc32` |
| `-h, --help` | справка по параметрам |

## Результат

В стандартный вывод выводятся полные пути файлов с идентичным содержимым:
на одной строке один файл, идентичные файлы идут подряд одной группой,
разные группы разделяются пустой строкой.

```
/path/to/a.txt
/path/to/copy-of-a.txt

/path/to/b.bin
/path/to/b-backup.bin
```

## Принцип работы

Каждый файл представляется последовательностью хэшей блоков размера `S`
(последний блок дополняется бинарными нулями). Файлы сравниваются
последовательно, блоки читаются с диска только при необходимости
и не более одного раза: чтение прекращается, как только блоки различаются.
